## 6. 下一轮唯一最值得进行的实验及理由

| 旧结论 | 修订 |
| --- | --- |
| bus/train梯度占15%–16%，监督已充分 | 撤回充分性结论；改名梯度范数占比（不可加和），只描述固定诊断帧 |
| 已经排除监督覆盖问题 | 撤回；64张train不能代表整个训练期 |
| 已证明主要是小目标被抹掉 | 降级为待验证；本轮提供真实尺寸桶观察，不能由类别名称直接推断因果 |
| 一个检查点近似恒等，所以排除更强预训练路线 | 撤回；一个真实雪检查点及其迁移范围不足以外推成熟模型路线 |
| 区间跨零，所以证明不更差 | 撤回；区间跨零不是等价性检验 |
| 裁剪C2失败，所以尺度顺序不是主因 | 撤回；未启用相同GT梯度的裁剪组不能隔离处理路径，本轮也未运行C2 |


**唯一建议：固定处理顺序的C1分块配置消融（tile640对1024，只读推理）。**

依据：清理变量后，v4的B对A更好，但C1的B AP50为0.282670、低于A的0.289145，不能继续声称三模型同向；C0/C1的train运行时检出均从A的3个降到B的2个；B没有对直接输入形成一致优势；当前A/B仍同时改变上下文和分块，真正剩余的混杂应先测清；修复后的Histoformer裁剪也显示非零局部上下文差，但不能直接外推为NAF因果；64张有正监督与梯度只证明样本覆盖，不支持直接提高总体任务权重或立即更换骨干。

实验设计：固定C1最终EMA及原24张train诊断样本，保留全部GT联合评分；不按GT逐图挑输出；两组都先在同一原尺寸RGB浮点图上复原，再用同一INTER_LINEAR缩放和共同padding；唯一配置差别为NAF tile640/1024，overlap64、现有均匀归一化融合公式相同；两组均FP32、autocast和TF32关闭，不量化；相同冻结YOLO、NMS、坐标反变换及.001/.25协议，复用本轮对应直接输入和1024路径记录作为参考；同时报告七类AP、bus/train/bicycle逐GT检出变化、FP及真实尺寸桶；明确tile大小改变了上下文/融合覆盖，不再将其误写成纯缩放顺序；不更新参数或优化器，不进行4000步训练；这是历史train诊断而非独立测试，先解决分块配置敏感性这一项问题。

本轮只提出该项，不自动启动。若该项涉及处理路径训练，两组必须实际启用相同GT任务梯度，同初始化、数据/优化预算、损失系数和配置；真正的处理路径对齐与裁剪采样分别命名，不能拿C0零任务梯度组当尺度控制组。一次短实验不能排除整个方向。

证据边界：val已经用于历史模型选择，帧与序列相关；train诊断样本也来自历史训练资源。对这些帧重新划分不使现有检查点变成独立测试。单seed、单检查点和少量bus/train目标限制推断强度。没有依据时不提高总体GT权重、不立即换骨干。
