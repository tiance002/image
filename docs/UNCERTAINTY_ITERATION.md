# 不确定性量化迭代记录

日期：2026-10-04（Asia/Shanghai）

## 本轮目标

将“不确定性热力图”从界面展示升级为可复查的量化结果，回答三个问题：

1. 不确定性是否与真实复原误差相关；
2. 不确定性是否发生全低或全高坍缩；
3. 当前保守融合是否在配对图像质量上优于直接复原。

## 实现内容

- 新增无SciPy依赖的Spearman相关系数；
- 新增不确定性校准分箱和ECE；
- 新增风险—覆盖曲线及AURC；
- 新增高/低不确定区域误差分离比；
- 新增逐图、总体和按天气类型汇总；
- 上传界面显示平均不确定性、90%分位值和高风险像素比例；
- 新增VS Code任务 `SafeRestore: Evaluate uncertainty`。

## 原型数据结果

使用 `configs/demo.yaml`、`runs/demo/best.pt` 和10张工程合成测试样本。共评价245,760个像素，GPU为CUDA设备。

| 指标 | 结果 | 当前解释 |
|---|---:|---|
| 恶劣天气输入 PSNR | 17.533 dB | 原始退化输入基线 |
| 直接复原 PSNR | 23.064 dB | 相对输入明显改善 |
| 保守融合 PSNR | 21.124 dB | 优于输入，但低于直接复原 |
| 不确定性均值 / 标准差 | 0.344 / 0.134 | 未出现常数输出 |
| 全局误差 Spearman | 0.441 | 达到预设原型门槛0.4 |
| 逐图 Spearman 均值 | 0.563 | 多数单图排序关系更明显 |
| ECE | 0.149 | 尚需校准，不能解释为概率准确度 |
| 风险—覆盖 AUC | 0.0344 | 作为后续模型对比基线，越低越好 |
| 高/低20%区域误差比 | 2.066 | 高不确定区域确有更大复原误差 |
| 不确定性低于0.05 / 高于0.95 | 0% / 0% | 无全低或全高坍缩 |

### 按天气类型拆分

| 天气 | 样本数 | 输入 PSNR | 直接复原 PSNR | 保守融合 PSNR | 逐图 Spearman 均值 |
|---|---:|---:|---:|---:|---:|
| fog | 4 | 14.737 | 24.760 | 21.562 | 0.619 |
| rain | 3 | 27.987 | 22.677 | 26.083 | 0.600 |
| rain_fog | 3 | 10.808 | 21.190 | 15.581 | 0.451 |

轻雨样本暴露了当前模型的主要失败模式：输入退化很轻，直接复原却进行过强修改，使PSNR下降5.31 dB。保守融合把该类结果恢复到26.08 dB，但仍没有超过原始输入。总体平均值不能掩盖这一退化。

## 结论与下一步

本轮支持“不确定性能够定位较高复原误差区域”，但不支持“当前保守融合已经最优”。直接使用预测不确定性作为融合权重过于保守，使总体PSNR下降约1.94 dB。下一轮优先加入退化强度门控：轻退化时限制复原残差，重雾和雨雾时允许更强复原；同时只在验证集上搜索融合温度、阈值或幂指数，然后冻结参数并在测试集复核。不得根据测试集反复调整。

以上结果只来自工程合成数据，属于原型证据，不是正式科研结论。正式结论仍需公开配对数据、真实天气数据和多随机种子实验。
