# 技术架构

## 1. 基线架构

第一阶段采用双分支 U-Net，而不是直接使用大型 Transformer 或扩散模型。原因是结构透明、显存需求可控、便于消融，并能先验证研究假设。

### 输入输出

- 输入 `weather`: `[B, 3, H, W]`，范围 `[0, 1]`。
- 输出 `restored`: `[B, 3, H, W]`。
- 输出 `uncertainty`: `[B, 1, H, W]`，范围 `[0, 1]`。
- 输出 `degradation`: `[B, 4]`，依次为雨概率、雾概率、雨强度、雾强度。

## 2. 组件

### 退化感知模块

使用浅层卷积和全局池化得到四维退化向量。前两维采用 sigmoid 表示天气存在概率，后两维采用 sigmoid 表示相对强度。向量经过 MLP 生成通道调制参数。

### 复原分支

编码器提取多尺度上下文，解码器恢复颜色、对比度和纹理。跳跃连接保留局部信息。

### 结构分支

使用固定 Sobel 核得到梯度幅值，再以轻量卷积编码。结构特征与复原特征在解码阶段融合。固定算子提供明确的图像处理先验，也使消融结果容易解释。

### 不确定性头

根据原始特征、复原特征和两者差异预测不确定性。训练初期使用复原误差构造软目标，后续再研究概率校准与检测错误监督。

### 保守融合

第一版采用图像级公式：

```text
final = (1 - uncertainty) * restored + uncertainty * weather
```

第二版改为特征级门控，防止高不确定区域完全恢复天气退化。

## 3. 损失

第一阶段：

```text
L1 = L_charbonnier + 0.2 L_edge + 0.1 L_ssim
```

第二阶段加入：

```text
L2 = L1 + 0.05 L_uncertainty + 0.01 L_uncertainty_regularization
```

第三阶段加入任务约束：

```text
L3 = L2 + 0.2 L_detection + 0.1 L_detection_consistency
```

各权重仅是起始配置，必须通过验证集选择，不得使用测试集调参。

## 4. 三阶段训练策略

1. 复原预训练：固定检测器不存在，仅训练复原、结构和退化感知模块。
2. 风险建模：加载最优复原权重，加入不确定性头和保守融合。
3. 任务感知微调：加载固定检测器，先只反向更新复原网络；最后可用检测器十分之一学习率联合微调。

## 5. 接口约定

模型 `forward()` 返回字典，不返回位置元组，以便后续增加深度、天气掩码或检测特征而不破坏调用方。

每次实验至少保存：

- 完整 YAML 配置；
- Git 提交号或源码快照；
- 随机种子；
- 最优和最后权重；
- 每轮训练/验证指标；
- 固定样例可视化；
- 测试集汇总表。
