# 展示原型阶段结果

日期：2026-10-01。

## 1. 结果性质

本页记录工程原型结果，不是论文结论。复原模型目前仅使用50对程序生成的道路示意图训练3轮；检测图片来自Ultralytics公开演示素材，天气由固定参数合成。该实验只能证明“数据—复原—不确定性—检测—结果保存”的全链路可运行。

## 2. 固定检测协议

- 检测器：YOLOv8n COCO预训练权重；
- 输入尺寸：640；
- 置信度阈值：0.25；
- NMS IoU：0.7；
- 类别：person、bicycle、car、motorcycle、bus、truck；
- 所有图像使用相同权重和参数。

配置位于 `configs/detector.yaml`，原始结果位于：

- `runs/detection/fog_comparison/detections.json`；
- `runs/detection/rain_fog_comparison/detections.json`。

## 4. 正确解释

当前不能判断消失的低置信person候选究竟是被消除的误检还是被遗漏的真实目标，因为本次演示样例没有在项目内建立独立人工真值。这个现象说明：

1. 只比较检测框数量是不够的；
2. 复原后置信度升降不能直接等同于安全性提升；
3. 下一阶段必须在有真实框标注的数据集上计算Precision、Recall和mAP；
4. 保守融合值得保留，因为它在当前样例上减轻了直接复原造成的置信度下降。
5. DCP在此单一样例上保持5个候选并提高bus置信度，说明传统方法是必要对照；这不代表其总体mAP更高。

## 6. 下一次结果升级条件

只有满足以下条件后，结果才进入“初步研究实验”：

- 使用正式公开数据；
- 测试图像具备独立真值框或配对清晰图；
- 数据划分经过泄漏检查；
- 至少加入恶劣天气原图和一个公开复原基线；
- 使用同一检测协议计算mAP、Recall和新增错误检测。
