# 两周展示版执行计划

展示截止目标：2026-10-15。

## 展示版必须回答的问题

1. 为什么普通去雨去雾不等于安全感知？
2. 系统如何保留道路目标结构并标识不可靠区域？
3. 当前原型是否能够稳定输入一张图并输出复原图、保守融合图和不确定性图？
4. 复原前后检测结果发生了什么变化？

## 最终展示内容

- 一张完整系统流程图；
- 5至10组输入、普通复原、本方法复原、不确定性图对比；
- 至少一张复原指标表；
- 至少一张检测前后对比表；
- 一个可现场运行的单图演示；
- 对1至2个失败案例的诚实说明；
- 后续研究路线。

## 展示版与论文版的区别

展示版允许使用小规模数据和初步指标，但必须明确标为“原型结果”。展示版不宣称达到先进水平，也不据此作自动驾驶安全结论。论文版仍需完整公开数据、多个基线、三随机种子、真实天气泛化和完整消融。

## 风险与替代方案

- 数据下载较慢：先用小规模公开样本完成闭环，再后台准备完整数据。
- GPU显存不足：使用256分辨率、batch size 2、混合精度和梯度累积。
- 检测指标暂时无提升：展示结构保持和不确定性机制，同时保留负面结果。
- 现场模型运行过慢：预加载模型，并准备固定样例离线结果。
