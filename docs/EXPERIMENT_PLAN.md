# 实验计划

## 1. 固定对照组

| 编号 | 输入/方法 | 目的 |
|---|---|---|
| E0 | 恶劣天气原图 | 测量不复原时的检测下限 |
| E1 | 清晰真值 | 测量理想输入的检测上限 |
| E2 | 通用复原基线 | 对比常规图像质量优化 |
| E3 | 天气专项基线 | 对比单天气先进方法 |
| E4 | 本项目基础双分支网络 | 验证结构先验 |
| E5 | E4 + 退化感知 | 验证统一模型适应性 |
| E6 | E5 + 任务一致性 | 验证检测导向复原 |
| E7 | E6 + 不确定性保守融合 | 验证安全贡献 |

具体基线在调研结束后锁定，选择原则是：代码可获得、许可清晰、任务匹配、硬件可运行。不得只选择明显较弱的老方法。

展示版检测协议已先行锁定在 `configs/detector.yaml`：YOLOv8n、输入640、置信度0.25、NMS IoU 0.7，只保留六类道路目标。正式实验可在验证集上重新确定一次阈值，但确定后必须对所有复原方法保持一致。

## 2. 数据分层

每个测试集均按以下维度单独报告：

- weather：rain、fog、rain_fog；
- severity：light、medium、heavy；
- object size：small、medium、large；
- domain：synthetic、real；
- class：六个道路目标类别。

## 3. 图像指标

- PSNR：配对数据像素保真；
- SSIM：结构相似性；
- LPIPS：感知距离；
- Edge-F1：复原边缘与真值边缘匹配情况。

真实非配对数据不报告伪造的 PSNR/SSIM，可报告无参考指标，但不得将其作为唯一结论。

## 4. 感知指标

- mAP@0.5；
- mAP@0.5:0.95；
- AP-small；
- Recall；
- 每类别 AP；
- 严重天气下的性能下降幅度。

## 5. 风险指标

### 新增错误检测率

固定检测器与阈值，对比复原前后预测。复原后新增且无法与真值匹配的检测框记为新增错误。

```text
AFPR = 新增错误检测框数量 / 测试图像数量
```

### 高置信错误率

```text
HCER = 置信度 >= 0.7 的错误检测框 / 全部错误检测框
```

阈值 0.7 必须在验证阶段锁定。

### 目标保持率

对恶劣天气原图中已正确检测、复原后仍正确检测的目标进行统计：

```text
OPR = 复原前后均正确检测的目标数 / 复原前正确检测目标数
```

## 6. 统计协议

- 核心比较使用 3 个随机种子；
- 报告均值、标准差和每个种子的原始结果；
- 相同测试图像上采用配对比较；
- 除总体平均外，必须展示最差天气类别；
- 超参数只用验证集选择；
- 测试集最多在方案冻结后进行正式评价。

## 7. 失败分析模板

每类至少保留 10 个样例：

- 雨雾残留；
- 过度平滑；
- 小目标消失；
- 虚假边缘或纹理；
- 颜色明显失真；
- 不确定性低但复原错误；
- 图像更清晰但检测变差。

每个样例保存原图、真值（如有）、基线结果、本方法结果、不确定性图和检测叠加图。
