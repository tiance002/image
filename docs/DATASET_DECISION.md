# 数据集选择与接入顺序

## 第一优先级：正式主线

### ACDC

- 用途：真实雨、雾道路检测、对应正常天气对照与不确定区域研究；
- 规模：官方列出4006张恶劣天气图，均衡覆盖fog、night、rain、snow；本项目首轮只使用fog和rain；
- 检测标注：官方`gt_detection_trainval.zip`覆盖train/val的2006张恶劣天气图；
- 对应图：每张恶劣天气图有同场景正常天气对应图，适合分析复原是否破坏目标结构；
- 限制：完整图像包约15.6GB，官方许可限非商业研究、教学等用途，下载前必须接受许可；
- 官方入口：https://acdc.vision.ee.ethz.ch/download

选择理由：ACDC同时覆盖本项目的雨、雾、道路目标检测和不确定性感知，比只含雾的RTTS更适合作为论文主数据。项目已实现标准COCO标注检查与固定YOLO评价脚本`evaluate_coco_detection.py`。

## 第二优先级：补充真实雾天检测

### RTTS

- 用途：真实雾天目标检测评价；
- 特点：VOC格式，包含真实雾图和目标框；
- 规模：官方RESIDE页面列出4322张真实雾图；
- 限制：没有逐像素清晰真值，因此不报告PSNR/SSIM；
- 官方入口：https://sites.google.com/view/reside-dehaze-datasets/reside-v0

RTTS最适合先验证“复原前后检测是否变化”，因此作为第一批正式接入数据。

2026-10-03状态：官方页面可访问，但原Dropbox短链接被跳转服务拦截；Hugging Face镜像在当前机器网络上连续连接超时。已完成VOC数据检查和检测评价工具，待合法下载入口可达后直接接入，不使用来源不清晰的临时压缩包替代。

### DAWN

- 用途：真实雨、雾等恶劣天气目标检测泛化；
- 特点：约1027张真实交通图，带检测框；
- 限制：无配对清晰真值，且原始发布渠道的下载与许可需要单独检查；
- 论文：https://arxiv.org/abs/2008.05402

DAWN作为第二个真实测试集，不作为像素复原训练集。

## 第三优先级：配对合成训练

### RESIDE合成子集

- 用途：配对去雾训练和PSNR/SSIM评价；
- 优点：天气图与清晰真值配对；
- 风险：合成到真实存在域差异；
- 策略：训练使用，最终结论必须由RTTS等真实数据补充。

## 暂不使用

- 来源或许可不清晰的二次网盘镜像；
- 只有图片、没有任务标签或来源说明的数据；
- 将测试集重新用于训练的整理版本；
- 纯生成式图像作为真实天气有效性的证明。

## 接入验收

每个正式数据集必须记录：下载来源、版本、许可、文件哈希、类别映射、样本数量、天气分布、场景划分和已知限制。未完成记录前不得进入正式结果表。

ACDC首轮验收额外要求：保留官方train/val地理划分；`rider`不直接并入`person`，除非形成单独映射实验；night和snow不进入当前主表；所有不支持类别和crowd标注必须在检查报告中计数。
