# 直接置信度保护：同预算续训对照记录（2026-10-25）

两组预设续训与完整 D0 已完成。**新增置信度保护相对同预算 control 有局部作用：恢复一个 train 检出，使主口径 mAP50 从 0.192734 升至 0.200764；但 bus 未解决且仍越过单类红线，因此拒绝用 guard 替换现有 v4。** 增益主要来自 train，不能解释为所有类别普遍改善。

本轮只使用已有本地数据、检查点、YOLO 权重和依赖；无数据或模型下载、无依赖安装。200 张雨雾与 406 张全天气均属于 ACDC val，已用于模型选择；不是独立 test。这是从同一个检查点开展的一次 seed42 续训比较，不是多种子结论。

## 问题与假设

历史 v4 以及后续 v6/v7 显示，少样本类别的 AP 下降可能被按框累计的 Recall/Precision 掩盖。bus/train 是本轮优先检查对象，同时保留完整七类与逐天气结果。过去五个 bus/train/truck 掉框案例是选定子集，不能代表全部损伤；不得再次据此声称“全量只掉五框”。历史纠正与 v6/v7 拒绝依据见 [前轮记录](OPTIMIZATION_2026-10-25.md) 和 [状态末尾](STATUS.md)。

本轮假设是：在冻结检测器中，直接惩罚复原图相对原始退化输入的高置信度类别概率下降，可能减少复原造成的置信度侵蚀。这个假设需要通过同预算旧配置续训对照检验，不能由实现正确或少量可视化样例直接确认。

## 训练约束的定义

实现见 [confidence.py](../src/saferestore/losses/confidence.py)，与既有冻结检测器特征损失的集成见 [perceptual.py](../src/saferestore/losses/perceptual.py)。

- 教师分支输入为**原始退化图像**，与复原学生图像使用相同的 256 中心裁剪视野；教师在 `no_grad` 下前向，分类 logits 进一步 `detach`。清晰参考图仍用于既有特征损失，不作为置信度教师。
- 读取 YOLO 的 **NMS 之前、sigmoid 之前的原始类别 logits**。本地 Ultralytics 8.4.104 的 `boxes/scores` 字典布局适配为统一锚点布局，与旧版多尺度 raw-map list 保持同一类别通道与锚点顺序。
- 对每张图像、每个支持类别，将所有尺度的教师 sigmoid 概率合并；保留概率 `>= 0.25` 的至多 `16` 个最高分锚点。类别顺序为 `person, bicycle, car, motorcycle, bus, train, truck`，对应 COCO ID `[0,1,2,3,5,6,7]`。
- 对所选锚点计算 `max(p_teacher - p_student, 0)^2`。学生概率提高不受惩罚；未选择的背景锚点与回归通道不参与此项损失。
- 每图每类先对所选锚点求均值，再对该图实际存在所选锚点的类别求均值，最后对批次求均值。没有所选锚点的类别不占类别分母；没有所选锚点的图像贡献可微的零值。

这是**每张图像内部、仅对实际有教师选择的类别做均衡**，不是数据集在类别上全局均衡，也不保证每个批次都有 bus/train。top-k 限制和类别内归一化避免仅因 car 锚点数量多而主导该项损失，但不能补出教师未识别的 train/bus。

新增损失权重预先固定为 **10.0**，独立于原特征损失权重 **2.0**；阈值 **0.25** 与 top-k **16** 同样在完整验证结果产生前固定，未扫描权重。例如单个所选锚点 `0.3 → 0.2` 的未加权平方下降为 `0.01`，乘权重后为 `0.1`，随后仍受上述类别与批次平均影响。该示例说明量级，不表示每个目标或批次均产生相同梯度。

教师选择是检测器预测，**不是 GT 框、GT 类别或真实正样本计数**。同位置类别概率保护不包含回归损失，不保证框定位、最终 NMS 保留、Precision、AP 或 OPR 一定改善；保持错误预测的置信度也可能带来虚警，因此必须单独检查 false positives。

## 已完成 control 的解读与归因边界

control 主口径 mAP50 相对输入保留率为 **94.3752% < 95%**；bus AP50 相对输入下降 **0.053920**，train 下降 **0.052805**，均超过单类 0.05 红线。fog mAP50 相对输入下降 **0.032751（3.2751 个百分点）**，超过天气 3 个百分点红线。一对一 OPR 为 0.955932，不能抵消这些失败。因此 control 未通过检测指标的 val 筛选规则；这仍不涉及完整 D1 或独立 test 验收。

## 最终筛选决定与证据边界

主要比较 `guard@52k − control@52k`，用于区分新增约束与额外 4000 步续训的影响；同时报告两者相对输入与 v4@48k 的变化。不能只证明 guard 好于历史 v4 就将收益归因于新增损失。

按 [验收标准](ACCEPTANCE_CRITERIA.md) 的现有规则检查：七类 mAP50 相对输入保留率至少 95%；一对一 OPR 至少 0.85；任一类别 AP50 相对输入下降不得超过 0.05；任一天气 mAP 下降不得超过 0.03；正确目标 Recall 下降不得超过 0.01。图像质量的 PSNR/LPIPS 红线如无对应评测应注明未验证。六类宏均值、micro 指标或 bus/train 个别改善均不能掩盖其它类别/天气红线。

这些规则可在 val 上作为候选筛选与风险诊断；D1 原标准要求固定协议的 ACDC test，本次仍不能宣称完成独立 test 验收。单 seed、少样本 train AP 波动、同一冻结教师的偏差以及没有直接定位约束，均是结论边界。

**最终决定：拒绝 guard 作为 v4 的替换候选，保留现有 v4。** guard 的主口径保留率为 98.3074%、OPR 为 0.976271，Recall/天气检查通过，但 bus 单类红线失败。train 的恢复和整体 OPR 改善是局部有用结果，不能抵消 bus 退化，也不能称为普遍改善。guard 主口径 0.200764 仍低于历史 v4 的 0.203157 与输入的 0.204221。

两组训练、预测、D0、教师覆盖、完整批次与冻结哈希核查均已完成。本次没有三种子验证、独立 test、置信区间或显著性检验，也未验证 PSNR/LPIPS 红线；不宣称完整 D1 通过。没有自动部署、替换权重或开展新的参数扫描。
