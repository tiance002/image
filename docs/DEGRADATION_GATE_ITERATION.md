# 退化监督与残差门控迭代记录

日期：2026-10-04（Asia/Shanghai）

## 问题来源

V1在雾和雨雾上复原有效，但轻雨测试输入PSNR已经达到27.987 dB，直接复原后反而降到22.677 dB，存在明显过度处理。

## 本轮假设

1. 显式监督退化编码器的雨、雾、强度和混合天气输出，可以改善条件特征；
2. 使用预测强度缩放复原残差，可以减少轻退化图像的过度处理。

## 实验控制

为避免将训练轮数差异误认为门控增益，使用相同数据、随机种子、12轮训练和损失权重训练两个版本：

- V2-Control：加入退化监督，不启用残差门控；
- V2-Gated：加入同样退化监督，并启用最小强度0.2的残差门控。

V1仅训练3轮，因此只作为历史原型，不用于证明门控因果效果。

## 固定测试集结果

| 指标 | V1历史原型 | V2-Control | V2-Gated |
|---|---:|---:|---:|
| 直接复原PSNR | 23.064 | **26.040** | 25.973 |
| 保守融合PSNR | 21.124 | 24.488 | **24.681** |
| 全局误差Spearman | 0.441 | **0.678** | 0.221 |
| 不确定性ECE | 0.149 | 0.125 | **0.094** |
| 高/低20%误差比 | 2.066 | **5.975** | 2.812 |
| 轻雨直接复原PSNR | 22.677 | 27.537 | **28.200** |
| 雾直接复原PSNR | 24.760 | **26.186** | 25.841 |
| 雨雾直接复原PSNR | 21.190 | **24.348** | 23.924 |

V2-Gated只在轻雨直接复原上领先，但在雾、雨雾和不确定性排序上退化。V2-Control达到不确定性Spearman门槛，同时总体和两类重退化结果更好，因此被选为新的演示模型。

## 门控诊断

V2-Gated预测的平均复原强度为：轻雨0.706、雾0.761、雨雾0.790。它确实按天气强度产生差异，但预测严重度MAE仍为0.229，门控区分度不足。当前全局连续门控不作为主方法结论，只保留为失败消融。

## 决策

- 演示模型切换到 `configs/demo_v2_control.yaml` 和 `runs/demo_v2_control/best.pt`；
- 保留V2-Gated权重和结果，用于消融与失败分析；
- 下一轮只在验证集上研究分类别或阈值式门控，不再根据当前测试集反复调整。

所有结果均来自10张工程合成测试样本，只是原型证据，不是正式科研结论。
