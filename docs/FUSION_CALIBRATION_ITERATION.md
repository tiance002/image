# 验证集保守融合校准记录

日期：2026-10-04（Asia/Shanghai）

## 目标

V2-Control的直接复原整体较好，但轻雨仍略低于输入；原始逐像素保守融合会明显损害雾和雨雾。此次只在验证集搜索融合参数，在冻结后对测试集运行一次。

## 方法

融合权重由两部分相乘：

1. 图像级门控：预测严重度越低，越倾向保留输入；
2. 像素级门控：不确定性越高，越倾向保留输入。

共搜索1500组严重度阈值、温度、不确定性阈值、融合强度和幂指数。选择目标为验证集按天气宏平均MAE最低，同时任一天气类别相对直接复原的MAE退化不得超过0.0005。

## 冻结参数

| 参数 | 数值 |
|---|---:|
| 严重度阈值 | 0.56 |
| 严重度温度 | 0.01 |
| 不确定性阈值 | 0.0 |
| 融合强度 | 1.0 |
| 不确定性幂指数 | 0.5 |

## 结果

| 数据划分 | 方法 | MAE | PSNR |
|---|---|---:|---:|
| 验证集 | 直接复原 | 0.02434 | 26.095 dB |
| 验证集 | 原始保守融合 | 0.04201 | 25.081 dB |
| 验证集 | 校准融合 | **0.02211** | **26.652 dB** |
| 冻结测试集 | 直接复原 | 0.02486 | 26.040 dB |
| 冻结测试集 | 原始保守融合 | 0.04579 | 24.488 dB |
| 冻结测试集 | 校准融合 | **0.02348** | **26.424 dB** |

### 冻结测试集分天气PSNR

| 天气 | 直接复原 | 校准融合 | 变化 |
|---|---:|---:|---:|
| fog | 26.186 | 26.271 | +0.085 |
| rain | 27.537 | 28.715 | +1.178 |
| rain_fog | 24.348 | 24.337 | -0.011 |

校准策略主要修复轻雨过度复原，同时基本保持雾和雨雾结果。雨雾的轻微下降在预先设定的验证约束范围内，但正式数据仍需重新校准，不能直接沿用这组原型参数。
