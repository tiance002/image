# 项目定义书

## 1. 项目名称

SafeRestore-RF：面向道路目标检测的保真型雨雾图像复原。

## 2. 要解决的具体问题

常规图像复原以 PSNR、SSIM 或主观视觉质量为主，可能出现两个安全问题：一是去除天气退化时同时抹除远处行人、车辆等弱小目标；二是生成并不存在的边缘或纹理，诱发检测器高置信误检。本项目研究在雨、雾和雨雾混合道路场景中，如何兼顾图像复原质量、目标结构保持和预测可信度。

## 3. 可检验的研究假设

H1：在常规复原骨干上加入结构保持分支，可以提升小目标 AP，并减少目标边缘损伤。

H2：加入检测特征一致性监督后，即使 PSNR 提升有限，检测 mAP 和召回率仍会优于仅使用像素损失的模型。

H3：像素级不确定性估计与保守融合能够降低复原引入的新增错误检测框，且不显著降低正确目标召回率。

H4：退化感知条件调制能提高单一模型对雨、雾和雨雾混合退化的适应能力。

## 4. 第一版研究边界

### 包含

- 单幅 RGB 图像；
- 白天道路场景；
- 雨、雾和雨雾混合；
- 六类道路目标；
- 合成配对训练与真实天气测试；
- 图像质量、检测性能和风险指标三层评价。

### 不包含

- 夜间低照度；
- 雪、沙尘和镜头污渍；
- 视频时序恢复；
- 端到端自动驾驶决策；
- 大型扩散模型；
- 安全认证或真实车辆道路部署。

## 5. 计划创新点

创新点只有在消融实验支持后才能写成最终论文贡献。当前计划为：

1. 退化感知的统一雨雾复原：用雨/雾概率和强度对复原特征进行条件调制。
2. 结构与任务双重保真：显式边缘分支结合检测特征一致性，保护道路小目标。
3. 不确定性引导的保守复原：预测像素风险，对不可靠区域限制激进修改，减少虚假目标。
4. 面向安全感知的评价协议：联合报告图像质量、检测性能、虚假检测率和高置信错误率。

## 6. 项目完成定义

满足以下条件才视为完成主线：

- 代码可在干净环境中安装，冒烟训练和单图推理均成功；
- 数据划分固定、无场景泄漏，并保留生成脚本与清单；
- 至少复现两个复原基线和一个固定检测器基线；
- 完成雨、雾、雨雾混合以及至少一个真实天气测试集实验；
- 完成全部核心模块消融；
- 与最强复原基线相比，检测主指标达到预设门槛；
- 对失败案例和不确定性校准给出定量及可视化分析；
- 训练配置、随机种子、权重和结果表可追溯。

## 7. 后续研究路线

完成主线后按优先级扩展：

1. 未知天气和开放集退化检测；
2. 夜间雨雾与低照度联合恢复；
3. 视频时序一致性与实时边缘部署；
4. 多传感器融合，例如可见光与热红外；
5. 风险感知检测器与选择性预测；
6. 面向真实道路的域自适应和持续学习。
