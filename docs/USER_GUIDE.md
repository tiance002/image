# 图片上传演示使用说明

## 打开项目

在VS Code选择“文件 → 打开文件夹”，打开：

```text
<LOCAL_PATH>
```

项目已配置解释器：

```text
<LOCAL_PATH>
```

如果VS Code右下角显示其他Python，按 `Ctrl+Shift+P`，执行 `Python: Select Interpreter`，选择上面的解释器。

## 启动上传界面

### 方法一：F5启动（推荐）

1. 确认VS Code打开的是“数字图像处理”文件夹；
2. 关闭仍指向旧目录的终端，再新建终端；
3. 按 `F5`；
4. 如需选择配置，选择 `SafeRestore: 启动上传演示`；
5. 等待终端显示 `Running on local URL`，使用其后面的实际地址。

首次加载模型可能需要十几秒，其间不要重复按 `F5`。

### 方法二：VS Code任务

1. 按 `Ctrl+Shift+P`；
2. 输入并选择 `Tasks: Run Task`；
3. 选择 `SafeRestore: Launch upload demo`；
4. 等待浏览器打开。

### 方法三：终端命令

在VS Code菜单选择“终端 → 新建终端”，执行：

```powershell
& "<LOCAL_PATH>" app.py
```

如果浏览器没有自动打开，请使用终端中 `Running on local URL` 后显示的地址，例如：

```text
http://127.0.0.1:7860
```

## 上传和查看效果

1. 点击“上传图片”；
2. 选择本地JPG、JPEG或PNG；
3. 点击“开始处理”；
4. 等待GPU处理完成；
5. 查看直接复原、保守融合、不确定性热力图、DCP传统去雾和目标检测。

建议先使用道路、车辆、行人、雨天或雾天图片。普通风景和室内图也能运行，但目标检测区域可能为空。

## 输出含义

- 直接复原：神经网络完整复原结果；
- 保守融合：高不确定区域减少修改的结果；
- 不确定性热力图：颜色越暖表示模型越不确定；
- 候选复原改动热力图：颜色越亮表示候选相对输入改动越大；
- DCP传统去雾：用于对比的传统图像处理结果；
- 目标检测：在保守融合图上检测道路目标。

指标区还会显示模型复原、DCP、检测安全门控和总处理链路耗时。点击处理后可下载单图完整实验包，里面包含七张输入/输出与诊断图、`metrics.json` 和带 SHA-256 的 `manifest.json`；单次结果也保存在 `runs/image_demo/`。“最近单图实验对比”会自动读取有效指标文件，显示最近十次结果，损坏或不完整记录会被跳过。

“平均像素改动”“显著改动像素比例”和“梯度结构一致性”都是相对输入的解释指标，不使用清晰真值，因此不能代替 PSNR、SSIM 或真实检测标注。它们主要用于回答候选改动是否过强，以及安全门控回退后最终输出是否恢复为输入。

## 多图片批量实验

1. 在“多图片批量实验”中一次上传 1–12 张 JPG 或 PNG；
2. 点击“开始批量复原与安全检测”；
3. 表格会显示每张图的雨/雾概率、强度、安全分数、采用或回退、目标数和总耗时；
4. 下载批量总 ZIP 和汇总 CSV。总 ZIP 的 `items/` 中包含每张图片各自的完整实验 ZIP，根目录的 `manifest.json` 记录哈希；
5. 批量运行使用同一冻结模型与阈值，适合无摄像头时比较多种道路天气图片，但不代替带真值的正式数据集评测。

自动检查可执行 `python app.py --check-batch`，使用内置雾图和雨图跑两张完整样例。

当前权重只使用工程验证数据训练，界面用于检查流程和展示交互，不代表最终论文效果。正式数据训练后只需替换权重，界面不需要重写。

## 视频仿真与结果下载

1. 在“无摄像头视频仿真”中上传 MP4，或保留预载的 ACDC 雾天序列；
2. 首次测试建议保持 30 帧、10 FPS、640 最大边、0.18 时序强度、逐帧安全门控和 FP32；
3. 点击“开始视频仿真”，等待结果视频和安全决策时间轴出现；
4. 在下载区优先下载 `*_result_bundle.zip`，其中包含结果 MP4、逐帧 JSON、CSV、时间轴 PNG 和 `manifest.json` 校验清单；
5. “最近视频实验对比”可比较有效精度、实测 FPS、P95 延迟、模拟丢帧、闪烁下降和安全回退次数。

FP16 只作用于 CUDA 复原网络，检测器仍为 FP32。当前硬件实测速度收益很小，因此演示和基线实验应保留默认 FP32；FP16 用于轻量化消融。

## 停止服务

回到运行服务的VS Code终端，按 `Ctrl+C`。关闭浏览器标签页本身不会停止服务。

## 常见问题

- 页面打不开：确认终端仍在运行，并使用终端显示的实际地址；端口被占用时可能自动改为 `7861` 等。
- CUDA内存不足：关闭其他占用GPU的软件，重新运行服务并上传尺寸较小的图片。
- 权重不存在：先运行 `SafeRestore: Smoke train`不能生成正式权重；当前项目已包含演示权重 `runs/demo/best.pt`。
- 没有检测框：可能图片没有六类道路目标，或目标置信度低于0.25。
