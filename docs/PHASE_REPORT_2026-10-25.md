复原模块已从"**伤检测**"（mAP50 0.1205，负收益模块）改善到"**统计上不劣于不复原**"

   想把 0.011 级差距测成显著需约 800 张评测图，ACDC 凑不齐。

## 四、这一轮新查清的三件事（本轮新增结论）

### 4.1 ACDC 的 ref 帧与退化帧**不是像素对齐**的

编号 100% 可匹配，但梯度相关仅 fog 0.065 / rain 0.285 / night 0.062 / snow 0.100。
⇒ ref 只能当"清晰源"做合成退化，**不能当配对真值**。这验证了之前走合成退化路线的正确性。

### 4.2 night/snow 的 ref 帧是**白天画面**

肉眼确认（`runs/pair_check/night_degraded_vs_ref.png`）：左=夜晚含车灯眩光，右=同街道白天。
⇒ 拿它当"清晰目标"会把夜晚洗成白天，**比现状更糟**。

### 4.3 night 掉点的根因被量化了

| 天气 | 亮度变化 | 饱和度变化 | 改动量 |
|---|---:|---:|---:|
| fog | 0.5 → 0.5 (±0.0) | 0.081 → 0.131 ↑ | 0.053 |
| rain | 0.5 → 0.5 (±0.0) | 0.137 → 0.178 ↑ | 0.054 |
| snow | 0.5 → 0.5 (±0.0) | 0.086 → 0.125 ↑ | 0.041 |
| **night** | **0.1 → 0.2（翻倍）** | **0.560 → 0.262（腰斩）** | **0.082** |

模型在把夜晚"洗成白天"。原因是训练目标全是明亮饱和的白天图，
模型学到"暗 = 欠曝 = 要提亮"，一遇到夜拍就乱动。

### 4.4 顺带完成：评测集泄漏核查（结论：未污染）

ACDC 官方 train/val 按序列划分不严格（fog val 100/100 与 train 序列重叠、snow 92/100）。
但重叠场景的 val 图与训练用 ref 帧梯度相关仅 0.072 —— ref 是另一时刻白天画面再经合成退化，
**像素与结构都对不上**，不构成信息泄漏。评测有效性成立。

## 五、下一步（按优先级）

### P0 · 正在执行：v4 全天气训练（11:25 已启动）

**方案：真实场景自监督对**（`scripts/build_real_scene_pairs.py`）

```
输入 = 真实 night/snow 退化帧 再叠一层像素对齐的额外退化
目标 = 真实 night/snow 退化帧 本身
```

为什么这样能治 night：
- 目标的明暗/色彩分布与真实夜间完全一致（实测 night 目标中位亮度 0.142 vs 真实 0.165；
  snow 目标 0.518 vs 真实 0.491，饱和度 0.068 vs 0.068，**几乎完全吻合**）
  ⇒ 模型无从学到"提亮"
- 输入比目标更暗、噪声更大（night 噪声 0.1125 vs 0.0389）⇒ 监督信号非空
- 像素严格对齐（额外退化只用加性/逐像素变换，**刻意避开 wet_road 的竖向位移**）

配套改动：`train_restorer.py` 支持 `--extra-manifest` 多清单混合采样
（实测附加占比 34.8%，期望 33.3%），采样逻辑同时从 `index % len` 改为按权重随机抽取，
批内样本多样性更好。

评测点切到 406 张全天气，保证选权重时能看到 night/snow 改善而非只看雨雾。

需要扩大样本或找同类数据集交叉验证，才能判断是真实下降还是抽样波动。
